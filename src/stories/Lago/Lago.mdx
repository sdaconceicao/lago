# Introduction

Lago is a design system for building web applications. It is a collection of components and utilities that can be used to build web applications.

## Getting Started

To get started with Lago, you need to install the package and import the styles.

```tsx
import "@code-x/lago/styles";
```

See the [installation guide](https://github.com/sdaconceicao/lago#installation)
for the package and required peer dependencies. Follow the
[complete token and theme setup](?path=/docs/design-tokens-setup--docs) to add
`ThemeProvider`, customize tokens, and configure light or dark mode.
